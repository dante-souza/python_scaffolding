# v0.3.0 — Phase 2: Bootstrap boundaries

Phase 2 defined the boundary between shell startup and Python policy.

It added the PowerShell adapter alongside Bash, minimal pre-Python diagnostics, conventional startup exit codes, authority handoff behavior, and documentation for the bootstrap responsibility split. Shell adapters remained intentionally thin: they resolve and start Python, while environment policy stays in the shared Python layer.
