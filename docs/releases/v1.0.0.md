# v1.0.0 — First stable Python Scaffolding baseline

`v1.0.0` marks the first stable release of the rebuilt Python Scaffolding contract.

The release consolidates Phases 0–4 and the Windows rebuild hotfix into one supported baseline:

- Makefile-first public command interface;
- Bash and PowerShell adapters;
- centralized `environment.toml` policy;
- shared Python environment/provenance layer;
- dual Python authority: native uv (default) or Conda;
- reproducible project `.venv` with fail-closed provenance;
- native uv managed-Python bootstrap;
- authority-aware doctor, sync, lock, rebuild, and dispatcher behavior;
- Linux/Windows × Conda/uv CI using the same Makefile lifecycle;
- Windows-safe `env-rebuild` from an active project `.venv`;
- concise canonical AI agent/skill hooks.

The SemVer archaeology leading here is preserved as `v0.1.0` through `v0.5.1`.
