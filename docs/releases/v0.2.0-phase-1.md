# v0.2.0 — Phase 1: Extract environment architecture

Phase 1 moved environment policy out of scattered implementation details and into a shared architectural contract.

The phase introduced `environment.toml` as the declarative source of truth and `scripts/environment.py` as the common policy/provenance layer. Bootstrap, doctor, and repository commands were redirected through that shared contract, with focused tests and documentation added around the model.

At this point Conda remained the sole Python authority; native uv authority was intentionally deferred.
