# Skill: Documentation Synchronization

Use when workflow, architecture, environment policy or public behavior changes.

## Placement

- `README.md`: how to use/build/run the project.
- `PROJECT.md`: why the project exists, scope, invariants and objectives.
- `AGENTS.md`: repository-wide agent operating policy.
- `docs/architecture/`: current system structure and boundaries.
- `docs/adr/`: durable decisions and their rationale.

Prefer updating the canonical source over copying the same policy into multiple tool-specific files.
